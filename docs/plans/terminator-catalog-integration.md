# Terminator catalog recovery

The default web catalog now includes the standard and assault Terminator squads alongside the existing pilot units. Own revision `expanded-1` uses the clean v2 contract and `lm-expanded-1` capability review. The reviewed clean package is in `web/public/catalogs/pilot-combined.json`, retaining the existing URL for fresh browsers and approved upgrades. Raw exports and private recovery evidence remain outside the repository. The individual Orks and Astartes pilot packages retain their original scope.

The standard squad has seven weapons and nine modes. Chainfist keeps separate Hunter/Standard modes and the explicit Monster/Vehicle target condition. Cyclone keeps Frag/Krak modes and the Storm Bolter bundle. The sergeant and ordinary models retain their distinct equipment options. The one-special-weapon-per-five limit remains an explicit equipment limitation, not an automatic legality check.

The assault squad has Twin Lightning Claws and Thunder Hammer. The shield is represented through separate equipped miniature variants with four wounds, derived from the three-wound base profile and the verified one-wound equipment bonus. Only the shield variants expose the hammer. Five- and ten-model compositions are available for both uniform loadouts; mixed equipment uses the existing group controls.

The adapter now binds reviewed fixed Sustained Hits and Twin-linked to the existing calculation engine. Twin-linked grants permission; the user still selects the wound reroll strategy. Blast, Fury of the First and the charge-dependent Terminatus Assault remain explicit calculation limitations. Deployment, doctrines, teleport resources and complete list legality remain outside the calculation.

Saved catalogs upgrade only through explicitly registered transitions after full validation and digest checks. Startup checks the configured local package first and falls back to the published package when no local package is configured, including production. An invalid upgrade keeps the previous catalog usable. Existing selections from the previous catalog revision remain expired and require reselection.

Validation: 43 confirmed individual MCP readings, 1,053 private recovery checks, 1,050 calculation combinations with probability-mass and cross-calculator agreement checks, 14 domain/application tests and 47 web catalog tests. Type checks and the production build passed. The local catalog endpoint returns the expanded package. Browser visual verification was unavailable because browser access was blocked.

Default catalog integration (11 October 2026): all three static packages validate with their registered digests; the expanded combined package passes 1,050 calculation combinations with probability-mass, inverse minimum and cross-calculator agreement checks. All 225 web tests and the production type/build checks pass. Four new synthetic regressions cover published upgrades, invalid successors, unrelated replacement chains and removal during a delayed upgrade. Browser verification of the production preview finds both squads, loads five standard Terminators against five assault Terminators with shields, confirms four wounds per shield-equipped model and generates the partial combat report.
