# LudoMaths

**LudoMaths** es una aplicación para calcular probabilidades y estadísticas en juegos de mesa, con versiones móvil y web. Actualmente está centrada en los combates de **Warhammer 40.000, décima edición**, y ayuda a los jugadores a comparar opciones y tomar decisiones durante una partida.

La aplicación permite definir las unidades atacantes y defensoras, sus armas, equipo y reglas especiales, y calcular el resultado de un combate siguiendo la secuencia de ataques, impactos, heridas, salvaciones y daño. Tiene en cuenta habilidades de las armas, repeticiones de tiradas y tiradas para ignorar heridas.

Los resultados muestran tanto los valores medios como las probabilidades de los distintos desenlaces: daño causado, bajas, miniaturas supervivientes y eliminación de una unidad. También permite estimar los ataques necesarios para alcanzar una probabilidad de eliminación determinada, calcular la probabilidad acumulada de eliminar al objetivo a lo largo de varias rondas y comparar mejoras.

Para facilitar su uso durante las partidas, permite guardar perfiles de unidades y consultar cálculos anteriores. La interfaz está disponible en español e inglés.
